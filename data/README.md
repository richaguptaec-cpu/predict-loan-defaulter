# Dataset Instructions

This project uses the UCI Default of Credit Card Clients dataset.

**Official source:** https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

## Download

1. Visit the official UCI dataset page.
2. Download the dataset.
3. Place the Excel file in this folder using the filename expected by the notebook:

`default of credit card clients.xls`

The dataset is not committed to this repository.

The dataset predicts whether a credit card client defaults on payment in the following month. It does not directly represent personal-loan defaults.
